# سامانه تحلیل بورس ایران

نسخه اول: دریافت تاریخچه قیمت روزانه نماد **فولاد** از API عمومی TSETMC و نگهداری آن در مخزن.

## اجرای خودکار
- از بخش **Actions** گردش‌کار **Update Foolad daily history** را باز کنید.
- برای اجرای فوری، **Run workflow** را بزنید.
- اجرای زمان‌بندی‌شده: شنبه تا چهارشنبه، حدود ساعت ۱۳:۴۵ به وقت تهران.

## خروجی‌ها
- `data/foolad_daily.csv`: تاریخچه روزانه؛ مناسب Excel و تحلیل.
- `data/foolad_instrument.json`: مشخصات نماد و اطلاعات اجرای آخر.

## اجرای دستی روی رایانه
نیازمند Python 3.10 یا جدیدتر؛ کتابخانه اضافی لازم نیست:

```bash
python scripts/fetch_foolad.py
```

## نکته مهم
این نسخه فقط نماد فولاد را پوشش می‌دهد. اجرای GitHub Actions به دسترسی شبکه GitHub به سرورهای TSETMC وابسته است؛ دسترسی موفق از موبایل، دسترسی موفق از GitHub را تضمین نمی‌کند. اگر TSETMC اتصال را رد کند یا ساختار پاسخ را تغییر دهد، اجرای Workflow خطا می‌دهد و باید گزارش آن بررسی شود.
