# سامانه تحلیل بورس ایران

این پروژه داده‌های بازار ایران را از API عمومی TSETMC دریافت و برای تحلیل و غربالگری ذخیره می‌کند.

## نسخه فعلی

### ۱) تاریخچه فولاد
- اسکریپت: `scripts/fetch_foolad.py`
- خروجی: `data/foolad_daily.csv` و `data/foolad_instrument.json`
- آرشیو دریافت‌شده در اجرای موفق اولیه: ۴٬۶۸۴ رکورد روزانه.

### ۲) غربالگر کل بازار
- اسکریپت: `scripts/scan_market.py`
- دریافت فهرست نمادها از MarketWatch و اطلاعات حقیقی/حقوقی از endpoint تجمیعی ClientType.
- خروجی CSV: `data/market_screener.csv`
- خلاصه و ۲۰ نماد برتر: `data/market_screener_summary.json`

شاخص‌های محاسبه‌شده:
- تغییر قیمت پایانی نسبت به روز قبل
- ارزش و حجم معاملات و تعداد معاملات
- خالص ارزش خرید حقیقی (در صورت وجود مقادیر ارزش حقیقی؛ در غیر این صورت برآورد حجم خالص × قیمت پایانی)
- قدرت خریدار حقیقی به فروشنده حقیقی بر اساس میانگین حجم هر کد
- نسبت حجم معاملات به حجم مبنا (این شاخص جایگزین میانگین حجم ۲۰ روزه نیست)
- امتیاز رتبه‌بندی شفاف و ساده بر پایه جریان پول حقیقی، قدرت خریدار و تغییر قیمت

## اجرا
در GitHub به بخش Actions بروید و **Update Iran stock market data** را انتخاب کنید؛ برای اجرای دستی روی **Run workflow** بزنید. گردش‌کار همچنین شنبه تا چهارشنبه حدود ساعت ۱۳:۴۵ تهران اجرا می‌شود.

## محدودیت‌های فعلی
- این نسخه غربالگر اولیه بر اساس snapshot بازار و داده تجمیعی حقیقی/حقوقی است.
- تشخیص حجم غیرعادی نسبت به میانگین ۲۰ یا ۳۰ روزه و شناسایی جاماندگی چندماهه هنوز پیاده‌سازی نشده است.
- برای نمادهایی که در پاسخ ClientType تجمیعی وجود ندارند، شاخص‌های حقیقی/حقوقی خالی یا صفر خواهند بود؛ ستون `client_type_available` این وضعیت را نشان می‌دهد.
- داده MarketWatch ممکن است خارج از ساعت بازار آخرین snapshot در دسترس را نمایش دهد.
- امتیاز رتبه‌بندی یک معیار آزمایشی است و توصیه خرید یا فروش نیست.
- موفقیت از شبکه GitHub به دسترسی TSETMC وابسته است؛ در صورت تغییر API یا محدودیت شبکه، گزارش Actions باید بررسی شود.

## اجرای محلی
Python 3.10 یا جدیدتر کافی است و وابستگی خارجی لازم نیست:

```bash
python scripts/fetch_foolad.py
python scripts/scan_market.py
```
